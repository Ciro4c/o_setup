osetup

Chọn nhóm đối tượng — học sinh, văn phòng, kỹ sư, thiết kế, kinh doanh, kế toán, marketing, giải trí, media… — và công cụ tự cài bộ môi trường và phần mềm mã nguồn mở phù hợp. Chạy online, hoặc tải sẵn thành gói offline rồi cài sau.

Tải osetup.exe (Windows) Xem mã nguồn trên GitHub

Windows: winget · macOS: brew · Linux: apt / flatpak. Không cần cài thêm thư viện Python.

Điểm nổi bật

Hai chế độ cài

Online: chọn → tải → cài ngay. Offline: tải thành gói trước, mang sang máy khác rồi cài không cần mạng.

Tách môi trường / phần mềm

VC++, .NET, Java, Python, Git… được cài trước, ứng dụng người dùng cài sau.

Không cài trùng

Quét máy một lần, đánh dấu “✓ đã cài” và tự bỏ qua mục đã có.

Chọn tất cả / gom gọn

Một ô chọn mọi nhóm; mọi khu gom gọn được bằng [-]/[+]; có chú giải và tooltip.

Khám phá GitHub

Quét top N repo nhiều sao theo chủ đề (self-host, CRM, ERP…), lưu vào danh sách riêng.

Mở rộng dễ

Thêm phần mềm / nhóm riêng bằng custom.json, không cần build lại.

Dùng nhanh

# Nhấp đúp osetup.exe để mở giao diện, hoặc dùng dòng lệnh:
osetup.exe install all --dry-run            # xem trước toàn bộ, chưa cài gì
osetup.exe install office student -y         # chế độ online
osetup.exe pack office -d D:\pack            # chế độ offline, bước 1 (có mạng)
osetup.exe offline-install -d D:\pack -y     # chế độ offline, bước 2 (không cần mạng)
osetup.exe check design                      # chỉ kiểm tra mục nào đã có / còn thiếu
osetup.exe discover crm --top 20             # top 20 repo CRM nhiều sao trên GitHub

Lưu ý: ID gói winget được soạn từ danh mục công khai nhưng chưa kiểm hết trên máy thật — chạy osetup.exe verify để phát hiện ID sai.
